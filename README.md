# WorkLogApp

WorkLogApp is an employee time-tracking and work scheduling application developed using Angular and TypeScript.

## Getting Started

### 1. Navigate to the project directory

```bash
cd mobile
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the application

```bash
npm start
```

Alternatively, to automatically open the application in your browser:

```bash
npx ng serve --open
```

### 4. Open in browser

The application is available at:

http://localhost:4200

The development server automatically reloads when source files are modified.

To stop the server, press `Ctrl + C` in the terminal.
